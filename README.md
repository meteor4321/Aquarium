# Aquarium

一個沉浸式的淡水全景水族箱，像一幅持續流動的高清動態壁紙。極簡、自然、安靜，沒有多餘介面，只有一個彷彿真實存在的水下世界。

## 如何使用

直接用瀏覽器開啟 [`index.html`](https://meteor4321.github.io/Aquarium/)。首次進入時，點擊畫面即可開始體驗。

## 水下世界

- **魚類**：群游小型魚、中大型觀賞魚與底棲魚，各自展現不同的游動方式與習性。
- **蝦與螺**：在底砂、水草間緩慢移動、覓食。
- **水草與藻類**：多層次水草、絲狀藻、輪藻與漂浮的浮萍。
- **造景**：岩石、沉木、苔蘚、球藻、落葉與底砂。
- **水下光影**：波動的水面、穿透水體的光束、砂地光斑、懸浮微粒與氣泡。

## 特色與互動

- **自然生物行為**：生物會轉向、加減速、停留與覓食，各有不同的游速、活動水層與習性。無須精確模擬生態，也能呈現自然的生命感。
- **半寫實 2D 全景**：透過景深、玻璃反光、水面與前後景造景，營造有層次的水下空間。
- **日夜變化**：白天是明亮的晨光綠，夜晚轉為深邃的藍與青藍色調。環境光影隨之變化，生物也會調整活動節奏，部分夜行性生物則更加活躍。
- **游標互動**：游標化為淡淡的光點，附近少數生物會好奇地靠近，隨後回歸原本的活動。
- **自由投餵**：點擊水族箱即可投放飼料，伴隨輕柔漣漪。不同生物會靠近、爭食、挑選或忽略飼料。
- **極簡介面**：僅保留晝夜切換按鈕，其餘空間留給水族箱本身。

## 技術

- **單一檔案**：所有 HTML、CSS 與 JavaScript 均包含在 `index.html`。
- **原生技術**：使用 HTML、CSS、Vanilla JavaScript 與 Canvas 2D，不依賴框架、建置工具、後端或外部資源。
- **桌面優先**：以桌面瀏覽器的流暢體驗為目標，並可在效能不足時自動降低渲染解析度。
